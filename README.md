# 🎓 College Event Management Website

A responsive front-end website designed to promote college events and improve student engagement through a clean, structured, and user-friendly interface.

---

## 📌 Project Overview

This project focuses on designing and developing a **college event management website** that centralizes all event-related information in one place.  
The website presents event schedules, speaker details, and registration options in a **clear, visually appealing, and easy-to-navigate layout**.

The primary emphasis of this project is **front-end UI design**, ensuring usability, readability, and consistent visual branding using **HTML and CSS**.

---

## 🎯 Problem Statement

College events are often communicated through posters, notice boards, or scattered messages across platforms, which makes it difficult for students to access complete and updated information.

This project solves that problem by providing a **single, centralized web interface** where students can:
- View upcoming events
- Understand schedules clearly
- Learn about guest speakers
- Register easily for events

---

## 🧠 Design & Development Approach

- Structured the webpage into **clearly defined sections** to guide users smoothly through content.
- Used **semantic HTML5** to improve readability and accessibility.
- Applied a **consistent color palette and typography system** to maintain visual branding.
- Designed layouts using **CSS Flexbox and Grid** for responsive behavior.
- Focused on **spacing, alignment, and visual hierarchy** to improve content scanning and user experience.

---

## ✨ Key Features

### 📅 Event Timeline Section
- Displays the event schedule in a **chronological and easy-to-understand format**.
- Helps users quickly identify event dates, timings, and overall flow.

### 📝 Registration Form UI
- Clean and minimal form layout for student registrations.
- Includes input fields, labels, and a call-to-action button (UI only).
- Designed with proper spacing and alignment for better usability.

### 🎤 Speaker Cards
- Visually organized cards highlighting guest speakers.
- Includes speaker name, role, and image placeholder.
- Built using **reusable CSS components**.

### 🔗 Footer with Social Links
- Footer section with college/club social media links.
- Adds consistent navigation and a professional finish to the website.
